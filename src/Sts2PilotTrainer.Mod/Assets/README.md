# Runmobile assets

`Runmobile/mod_image.png` is the 64×64 RGBA source for the image the game's mod list loads at `res://Runmobile/mod_image.png`.
`Runmobile/mod_image.png.import` and its named `.godot/imported/*.ctex` output were generated by Godot 4.5.1 and stay beside it because the retail loader needs the imported texture as well as the PNG.
`tools/pack-runmobile-icon.py` packs exactly those three resources into `Runmobile.pck` during `scripts/package-mod.sh`.
