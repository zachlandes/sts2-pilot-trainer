# Every way a decision can reach the game on this build - each game action a net
# action becomes, each choice the client syncs and where, each message it sends and
# who sends it, each overlay screen, each room - walked off the game assembly by
# DecisionSurface, with the recorder's account of it: claimed by the rows of the
# engine command table that observe it, or excused in DecisionLedger with a class
# and a reason. A candidate accounted for neither way is UNCLASSIFIED and fails
# engine-commands, which is what a game update that adds one meets first.
# Regenerate with
#   ./scripts/arbiter engine-commands --update
